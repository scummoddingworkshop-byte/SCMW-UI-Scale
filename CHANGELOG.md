# Changelog

## 1.0.0 — 2026-10-26

First release.

- Live UI scale using the game's own layout scale.
- **Ctrl + −** and **Ctrl + +** change the size in 10-point steps.
- **Ctrl + 0** resets to 100%.
- Number-pad **−** and **+** are supported.
- The chosen size is saved between sessions in
  `%LOCALAPPDATA%\SCUM\Saved\SCMW_UIScale.txt`.
- Works in the inventory, crafting, HUD and main menus.
- No game files are edited; remove the mod to return to normal.
